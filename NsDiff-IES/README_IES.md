# NsDiff on the merged IES dataset (energy + weather)

This adds an end-to-end pipeline on top of the official NsDiff code that

1. **merges** `Total_energy.csv` + `Total_weather.csv` into one multivariate
   hourly series,
2. **trains** NsDiff on it (with tqdm progress bars, on **GPU 4**),
3. **produces the three figures** (Fig.3 daily profiles, Fig.4 correlation
   matrices, Fig.5 PDFs) and
4. **computes the metric table**: `CRPS, PSD, APD, Avg Std, DTW, MAE, RMSE, ACF`.

---

## 0. What was added

| File | Purpose |
|------|---------|
| `data_merge.py` | merge the two raw CSVs → `data/IES/IES.csv` (+ `IES_base.csv`) |
| `src/datasets/ies.py` | `IES` dataset class (11 channels, hourly, freq=`h`) |
| `src/datasets/__init__.py` | registers `IES` |
| `src/eval_ies.py` | Fig.3/4/5 + the 8 metrics (pure numpy/matplotlib) |
| `src/experiments/NsDiff_IES.py` | `NsDiffIES` experiment: `train_eval` / `generate` |
| `scripts/NSDiff/IES.sh` | training command (cuda:4) |
| `run_ies.sh` | one-shot: merge → train → figures + metrics |

### Merged dataset layout
The two files are aligned on `Year, Month, Day, Hour` (78 888 hourly steps,
2014-01-01 → 2022-12-31, no missing values). Channel order — **the first four
are the paper targets**:

```
0 Electricity (Electrical load)  1 Cooling (Cooling load)
2 Heat (Heating load)            3 PV (PV power)
4 Temperature 5 Dew Point 6 Humidity 7 Wind Speed
8 Wind Gust   9 Pressure  10 Precip           (weather covariates)
```

## 1. Install

```bash
cd NsDiff-main
pip install -r ./requirements.txt          # torch_timeseries, torch, wandb, fire,
                                            # tqdm, matplotlib, scipy, pandas, numpy ...
```
> Install a CUDA-enabled PyTorch that matches your driver before the rest if
> `torch` is not pulled in automatically.

The raw `Total_energy.csv` and `Total_weather.csv` are already placed under
`data/IES/`. (`IES.csv` is regenerated by the merge step, so you can delete it.)

---

## 2. Run everything (GPU 4)

```bash
bash ./run_ies.sh
```

or the two steps manually:

```bash
export PYTHONPATH=./

# merge
python3 data_merge.py --dir ./data/IES

# train on GPU 4, then auto-generate figures + metrics
CUDA_DEVICE_ORDER=PCI_BUS_ID python3 ./src/experiments/NsDiff_IES.py \
    --dataset_type=IES --device="cuda:4" --batch_size=32 \
    --windows=168 --horizon=1 --pred_len=24 --epochs=30 --patience=8 \
    train_eval --seed=1
```

`windows=168` (one week of history) → `pred_len=24` (a one-day scenario), which
is what Fig.3 shows. Progress bars appear for training, validation, testing and
generation.

### Re-plot without retraining
```bash
CUDA_DEVICE_ORDER=PCI_BUS_ID python3 ./src/experiments/NsDiff_IES.py \
    --dataset_type=IES --device="cuda:4" \
    --windows=168 --horizon=1 --pred_len=24 \
    generate --seed=1
```

## 4. Metric definitions

All metrics compare the **real** test windows against the **generated** samples,
on the four IES targets, in per-unit (each channel ÷ its series max).

| Metric | Definition |
|--------|-----------|
| **CRPS** | sample-based Continuous Ranked Probability Score, `E|X−y| − ½E|X−X'|`, averaged over all points & targets |
| **PSD** | mean `|logPSD_real − logPSD_gen|` over frequencies (rFFT along the horizon) → spectral-shape error |
| **APD** | *Absolute Pearson-correlation Difference*: mean off-diagonal `|Corr_real − Corr_gen|` of the 4×4 matrices in Fig.4 |
| **Avg Std** | mean standard deviation across the S generated samples → generation diversity |
| **DTW** | mean Dynamic-Time-Warping distance between real and generated-mean windows |
| **MAE / RMSE** | point error between real and generated-mean |
| **ACF** | mean `|ACF_real − ACF_gen|` over lags → autocorrelation-shape error |

> These follow the standard scenario-generation formulations. If your paper
> fixes a slightly different form for `APD`/`PSD`/`ACF`, edit the corresponding
> function in `src/eval_ies.py` — they are small and self-contained.

## 5. Tuning

- **Faster sampling**: lower `testing.n_z_samples` in `configs/nsdiff.yml`
  (default 100). CRPS / Avg Std use these samples, so keep ≥ ~50 for stable
  probabilistic metrics.
- **Different GPU**: change `--device="cuda:N"`.
- **Longer/shorter scenarios**: change `--pred_len` (and re-run `generate`).
- **More capacity**: `--d_model`, `--e_layers`, `--diffusion_steps` are exposed
  as CLI flags (see `NsDiffParameters` in `src/experiments/NsDiff.py`).
